# Itishree Weds Bikram — Bride-side wedding website

A responsive, bride-first invitation website with a refined Bhubaneswar / City of Temples identity.

## Files

- `index.html` — all invitation copy, sections, map links, and phone links.
- `assets/styles.css` — responsive visual design.
- `assets/script.js` — mobile navigation.
- `assets/*.jpg` — image slots referenced by the page. Add locally licensed/photos you own before publishing (see below).

## Visual direction

- Elegant contemporary editorial style: warm ivory, muted sandstone, deep burgundy, antique gold.
- Bhubaneswar touch through temple-arch framing, sandstone palette, city heritage imagery, and an Old Town focus.
- No games, treasure hunts, or separate Odia-culture/game section.
- Bride-first hierarchy: Itishree, her parents, and Sundarray family appear before Bikram and his parents.

## Add image assets before publishing

The HTML references the following files in `assets/`:

1. `lingaraj-hero.svg` — hero and Old Town feature image. Use a high-resolution photo you own or have permission to use.
2. `rajarani-temple.svg`
3. `dhauli.svg`
4. `khandagiri-caves.svg`
5. `mukteswar-temple.svg`
6. `nandankanan.svg`
7. `ananta-vasudeva.svg`
8. `kalabhoomi.svg`

The page remains readable if an image is absent, but the landmark cards will show empty image placeholders. Use your own photos or images with clear reuse rights; do not assume images from search results are free to republish. Recommended dimensions: hero 1200×1600 portrait; landmark images 1200×800 landscape, JPG/WebP, compressed for web.

## Deploy on GitHub Pages

1. Open `https://github.com/Itiatgit/itishree-weds-bikram`.
2. Upload `index.html` to the repository root.
3. Upload the entire `assets` folder, preserving filenames and paths.
4. Commit to `main`.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then Save.
8. Wait for GitHub Pages to publish. The expected URL is `https://itiatgit.github.io/itishree-weds-bikram/`.

## Before sending the invitation — confirm

- Exact spelling / styling of parents' names and family acknowledgement.
- Four contact numbers are intentionally public on the invitation site.
- Maps links are Google Maps search links built from the supplied venue addresses. Verify each pin and update to a precise venue pin if available.
- Confirm that the residence address should be displayed publicly. Consider linking to a nearby landmark or shareable map pin instead of showing the full house address.
- Check whether all guests should receive English-only copy. This first package is English-only by design.
- Test all links and layout on Android, iPhone, and desktop before sharing.
